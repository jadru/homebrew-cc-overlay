# 90-Day User Interview Guide

Use this guide for 10 short interviews with people who actively use Claude Code, Codex, or both. Do not pitch first; reconstruct the most recent real decision.

## Recruiting screen

- Used an AI coding CLI in the last seven days
- Has encountered a rate limit, slowed usage to avoid one, or switched tools because of capacity
- Mix single-provider and multi-provider users

## 20-minute script

1. “Walk me through the last time you checked whether you could keep coding.”
2. “What did you look at, and what decision did you make?”
3. “What was costly or uncertain about that decision?”
4. Show the Run / Wait / Switch recommendation. “What would you trust or distrust here?”
5. “When would this become part of your normal workflow?”
6. “Which capability, if any, would justify a one-time purchase?”
7. Ask price sensitivity only after value discussion: $19, $29, $39, or free-only.

## Decision rule

Synthesize only repeated behavior, not feature votes. Keep the core local monitor free. Test the $29 one-time Pro gate only if at least 3 of 10 interviewees independently name the same high-value trigger and the scorecard shows at least 30% paid intent.
